# 学习罗盘使用指南

适用版本：`2026.10.13`，Windows 10／11 x64（公开试用版）。

本轮另含月视图、实际学习日历、快捷录入与待安排收集箱，以及优先级和今天重点。可在设置页查看版本及构建时间。本指南随软件一起提供；打开、搜索和阅读指南不联网，也不使用 API 额度。

## 首次体验

### 阅读较长的任务说明

双击任务打开详情后，任务说明、完成产出和收获与问题会自动换行，并保留多行阅读空间。内容较长时可在文字区域滚动；窗口较小时可滚动整张表单，底部“保存/取消”始终保留。Enter换行，Tab移到下一个输入项。

手动添加任务、快捷录入、周期任务及创建计划中的长文字也使用同样的阅读方式。已复盘任务的说明和完成产出只读，仍可选中文字复制；查看或取消不会改任务。

### 先记下来，稍后安排

在“今日 → 任务管理 → 快捷录入”打开输入窗口，也可在主窗口按Ctrl+Shift+N。填写名称和预计分钟，可选说明、所属计划、优先级和置顶。

- 不勾“现在选择日期”：保存到“待安排收集箱”。它还不是某一天的任务，不占每日预算，也不能专注或打卡。
- 勾“现在选择日期”：选择日期后直接保存为任务。可能超过预算或计划上限时，仍会另外询问，默认取消。
- 到“任务管理 → 待安排收集箱”搜索或双击事项，选日期和所属计划后确认安排。任务沿用原ID，从收集箱移出；之后到该计划或计划库固定“独立任务”箱查找，不是丢失。

如需在其他软件中也能打开录入窗口，到“设置 → 外观与提醒 → 全局快捷录入”勾选启用，填写组合键后点击应用。默认关闭；示例Ctrl+Alt+N。被其他程序占用会明确提示，不能抢占。关闭学习罗盘后快捷键失效；取消勾选并应用即可停用，主窗口内快捷键仍保留。

### 优先级、置顶和今天重点

右键一项任务，选择“优先级与今天重点”。可选普通、低、中、高，或置顶、标为今天重点。它们只改变列表显示顺序，不改安排日期、预计分钟或完成状态，也不会帮你挪动其他任务。

今日页勾“只看今天重点”后，只筛选本来属于今天或逾期范围的重点任务，不会把未来任务改成今天。重点标记过了当天不再显示；置顶和优先级会保留。

### 看整个月，并预览改期

在“周视图”点击“月视图”。每天显示全部活动任务的预计安排；设置过总预算的日期会同时显示预算，超出会写明“超预算”。筛选单个计划也不会把全局负荷变成该计划的负荷。小窗口可滚动查看月历。

单击日期查看该日明细，双击任务打开详情。把任务拖到另一日期只会打开改期预览：先核对原日期、新日期、负荷和保留原因，点击“确认改期”才保存。取消不会改日期。已完成、已有学习记录、已复盘等受保护任务不能直接拖走；预览会解释原因。拖动或预览期间出现新修改、记录或预算变化，请重新预览，不会覆盖新数据。

### 按实际日期看学习用时

“今日 → 学习工具 → 实际学习日历”按真正发生的日期显示新专注和按日期补记的用时。日历可切换月份，另外两页是每日记录和每周趋势。连续天数只计算当前显示月份，不等于从软件启用以来的最长连续天数。

今日圆点在日期旁边，学习时长在日期下方，不重叠。日历用分钟简写（保留一位小数）；摘要、每日记录和每周汇总显示精确分秒，例如“4 分 32 秒”，不会把显示取舍写回原记录。

- 新专注按观察到的计时秒数记录日期，跨午夜分到两天；暂停、退出及休眠间隔不补算学习时间。
- 右键任务 →“补记实际学习日期”：选择已经学习的日期及本次分钟。保存后增加该任务的人工补记累计；未开始会变为进行中，不自动完成。不要再在旧累计输入框重复补同一段时间。
- 选中一条人工补记可撤销，须确认；只扣除这次补记，不清除其他记录或改变当前状态。专注计时不能在这里手工删改。
- 旧版只存累计值，不能知道具体哪天学的。这部分显示为“未确定发生日期”，不塞进日历，也不从安排日期推算。旧“学习统计”仍是按任务安排日期汇总当前进度，和这个新入口的含义不同。

### 不填 Key，也可以先试用

1. 打开软件，在“今日”点击“载入两周 Python 体验样例”。
2. 到“计划库”选择样例，双击一项任务。
3. 填写状态、笔记或用时，点击“保存”。
4. 到“周视图”查看任务日期。今天没有任务，不代表计划没保存；可能安排在其他日期。

不想用样例，也可以在“今日 → 任务管理 → 添加自己的任务”填写任务，无需模型。

### 按类别寻找操作

“今日”有两个操作菜单：“任务管理”用于添加、编辑和安排逾期任务；“学习工具”用于统计、周期复习和执行步骤。

在计划库先选中计划，再打开对应菜单：

- **任务安排**：添加任务、编辑选中任务、调整日期、分组与步骤、暂停或恢复学习。
- **计划管理**：重命名、归档、创建副本、删除。删除仍需输入“确认删除”，不能直接点菜单删除。
- **AI 辅助**：用模型调整计划、生成本周复盘。发送前会提示可能使用模型额度。
- **历史与数据**：查看调整历史并回溯、查看原需求、继续草稿、导出 JSON。

点击菜单外面或按 Esc 可以收起；也可用上下方向键选择，再按空格或回车打开。任务旁的“开始专注”和双击编辑保持不变。

菜单刚打开时不预选第一项。鼠标移到哪一项，哪一项才高亮；上下方向键也能切换高亮，回车或空格执行，Esc关闭。

### 右键操作一项任务

在今日、计划库任务表、周视图卡片或明细、任务分组列表中，把鼠标移到具体任务上点击右键，即可打开同一套任务菜单。菜单顶部写明当前任务；只操作右键的这一项，不会把此前选中的其他任务或搜索隐藏的任务一起修改。空白处和分组标题不是任务，不会弹出任务菜单。

菜单包含查看/编辑内容与预计用时、修改日期、修改完成状态、填写笔记和补记用时、开始专注、设置提醒、分组与执行步骤、AI修改保护、AI调整该任务、删除手动任务等入口。编辑入口仍打开原窗口并定位到相应输入框；必须点击保存才生效。再次打开同一编辑窗口不会清除未保存内容。“AI调整”先打开范围确认，不会在右键或打开菜单时调用模型。

不能使用的操作会置灰并写明原因。例如暂停、归档或已完成任务不能新开专注；已复盘任务不能修改内容或完成状态，但仍可补记笔记、用时和勾选现有步骤。手动任务本就不会被AI改写，不需另设AI保护；生成任务暂不支持从此入口单项删除。

删除手动任务会再次询问，默认取消；会连同它的学习记录一起删除。确认期间若任务、分组或步骤产生新变化，不会继续删除。已有未关闭的任务/步骤编辑窗口或关联专注时，请先处理完再删除。也可用键盘菜单键或Shift+F10打开当前任务菜单，上下键选择、回车执行、Esc收起；小屏菜单可滚动。

### 搜索任务与找回已完成任务

“今日”、计划库任务表和“任务分组与执行步骤”窗口都有任务搜索。默认是**仅任务名称**：输入“编写”，只返回名称里有“编写”的任务。右侧切换为**全部内容**，才会同时搜索名称、说明、完成标准、安排日期和所属计划；输入多个词时，结果须同时匹配这些词。

全部内容搜索时，任务名下方会注明“说明命中：…【编写】…”等字段和片段。比如“跨周切换测试”的名称没有“编写”，但说明包含“编写测试”，就会列出并说明原因。鼠标停在任务名称上，会显示圆角预览卡，分开列出日期、状态、说明和完成标准，并标明匹配位置；不重复显示整段内容。长内容会省略，双击任务可查看完整资料（分组窗口中双击管理执行步骤）。仅名称模式不额外显示重复的命中说明；清空关键词后也会收起片段，不修改原任务名称。

每个入口可以独立切换范围，刷新、最小化或隐藏后恢复会保留选择；新建分组窗口或重新启动软件时默认仅名称。日期关键词（如`2026-10-20`、`2026/10/20`）请选全部内容；“限定日期”的起止日期筛选不受搜索范围影响。点输入框右侧清除键可恢复；匹配数只统计当前页原有范围内的任务，不会绕过今日/计划筛选。

小窗口会优先保留任务名的可读宽度，任务表底部可横向滚动到日期、状态和操作；纵向滚动可看更多结果。计划库窗口较矮时收起较长的计划说明，鼠标停在计划标题上可查看，放大窗口后恢复显示。

要按日期范围查找，勾选“限定日期”，选择起止日，两端都包含当天；结束日不能早于开始日。计划库还可以选择“已完成”“未完成”等状态。筛选只改变眼前列表，不修改日期、状态、统计或时间预算。

今日默认显示今天和更早的未完成任务。勾选“查看已完成”，再显示**安排在今天**的已完成任务；取消勾选就隐藏。这里不是按“实际完成时刻”统计，旧任务没有保存该时间。过去或未来日期的已完成任务，要到计划库查找。

计划库左侧固定的“独立任务”箱，存放不属于任何计划的任务。初始可查看全部日期、全部状态，完成后仍保留；若没看到，清除搜索、取消日期限定并选择“全部状态”。这个入口不能删除或归档，但任务本身仍可打开、编辑，手动任务可单独删除并确认。

独立任务箱不是AI学习计划，不参与计划复盘、暂停或计划删除。可以添加独立任务、分组和步骤；改日期请双击任务。完整独立任务记录使用“设置 → 数据与备份 → 立即备份”保存，不使用单计划JSON；“历史与数据 → 继续草稿”在这里仍可打开。

### 找回指南窗口

点击左下角“使用指南”，或按 F1。打开期间，所有入口共用一个独立窗口，不会越开越多。

关闭指南后可以再次打开，仍保留上次的搜索词、章节和窗口大小。不必重启软件，也不会因为先关闭“添加任务”或“调整排期”窗口而打不开指南。

指南最小化后，再按 F1 就能恢复。也可以通过 Alt+Tab，或任务栏学习罗盘图标组中的缩略图切换。搜索框按关键词筛选章节。

统计、添加任务、调整排期、步骤、历史和创建计划等普通窗口与主窗口平级。点击哪个窗口，哪个就在前面；主窗口不会因为工具还开着就无法操作。再次点击同一入口会找回原窗口，不重复打开。

从工具窗口打开指南，会先把指南带到前面，之后你仍可切回主窗口或其他工具。删除、超限等短暂确认框只保护当前操作，确认或取消后继续；在确认框里打开指南时，指南可在确认框上方阅读，不会永久置顶。

### 完全退出与更新

点主窗口右上角关闭，默认只是收进托盘。要真正退出，请在右下角托盘图标上右键，选择“完全退出”。覆盖更新前先保存操作，再完全退出。

首次启动可能较慢，不要反复双击。便携版必须保留整个文件夹，不能只复制 exe。

## 接入自己的模型

### 添加连接

1. 打开“设置 → 模型连接 → 添加连接”。
2. 选择服务商，填写配置名称、服务地址、模型 ID 和该服务商的 API Key。
3. 按服务商说明选择接口和输出格式，再保存。
4. 可点击“测试连接”。这会发送真实小额请求，可能收费。

模型列表获取失败时，也可以手动填写模型 ID。模型列表、简单 JSON 测试和完整计划生成是不同请求；一种成功，不保证另外两种也成功。

### 各选项是什么意思

- **服务地址**：服务商提供的 API 地址，不是聊天网页地址。不要在地址中放 Key、密码或查询参数。
- **接口类型**：Responses 或 Chat Completions。以服务商支持范围为准，软件不自动切换。
- **输出格式**：严格 JSON Schema 或 JSON 模式。两种都要通过本机任务规则检查，不能靠切换格式绕过时间上限。
- **Chat 输出上限字段**：通常是 `max_tokens`，部分服务要求 `max_completion_tokens`。
- **默认代理／直连**：默认使用现有网络环境。只有选择“直连”才绕过环境代理；不要为排查问题同时改动所有设置。

原生 Claude／Gemini 接口暂不支持；只有服务商提供兼容接口时才能接入。ChatGPT 网页会员不等于 API 额度。

### 密钥、费用与取消

Key 默认存入 Windows 凭据管理器；选择“仅本次使用”后，退出软件就要重新输入。Key 不写入学习数据库、日志和备份。不要把 Key 粘进目标、笔记或发给别人。

获取列表最多等15秒，连接测试30秒，生成或调整每次请求240秒；旁边显示倒计时。点击取消后，软件不再等待，也不保存迟到结果，但服务端已收到的请求仍可能计费。

顶部切换模型只影响新流程。已有草稿保留原连接；要使用新配置，在主窗口选好连接，再到草稿点击“换用顶部模型”。

## 创建学习计划

### 填写资料

点击“创建计划”，填写科目、目标、基础、已掌握内容、预期产出、开始日期、周数、学习日及每日分钟数。

“科目”填简短分类，例如 Python、英语或软件开发；详细想法放在目标里。周期1–8周，每周1–7天，每日15–240分钟。

### 确认后才保存

1. 点击“发送资料，生成概略”。模型可能补问关键问题，最多2轮、每轮1–3题。可选参考选项，也可自己输入、不确定或跳过。
2. 查看3–5点概略。摘要共80–140字；点“查看安排与产出”可展开详情，不会再次请求模型。
3. 不满意时，点击对应点的“修改”，或返回资料。发送修改意见会使用额度。
4. 确认方向后生成每日任务，先检查任务、日期、时长和产出。
5. 点击“保存计划”才成为正式计划。快速生成只跳过追问，不跳过概略确认。

草稿会保存在本机。失败、取消或关闭窗口后，可从“继续草稿”接着做，不必重新填写全部资料。草稿列表显示创建和修改时间；仅查看不会刷新修改时间。旧版没有记录的创建时间显示“旧版未记录”。

### 输入框与日期

下拉框、数字、日期和时间框：只有鼠标在最右侧箭头上，滚轮才改值。停在文字区滚动不会误改数值；展开的列表可以正常滚动浏览，点击选项才确认。

日期可直接输入 `YYYY-MM-DD`，也可打开日历选择。左右箭头翻月，月份下拉跳月，年份可以输入。翻月不等于选日期；按 Esc 取消，点击“今天”选今天。

## 修改与保护计划

### 手动添加任务

1. 在“今日 → 任务管理 → 添加自己的任务”，或周视图点击“添加任务”；在“计划库 → 任务安排 → 添加任务到此计划”可预选当前计划。
2. “放在哪里”选择已有计划，或“独立任务（不属于任何计划）”。
3. 填写名称、日期和预计用时。具体说明、完成标准及提醒可选。
4. 点击“添加任务”。不需要 Key，不调用模型。

加入计划的任务计入该计划的完成数及时间安排，但不改变原来 AI 生成的学习周次。超过该计划的每日／每周上限时，软件会先列出超限情况，默认取消；点击“仍然保留安排”后才保存。原来的上限设置不会被放宽。

独立任务也能打卡、计时和提醒，并计入每日总预算；它没有单份计划的时长上限。手动任务本身可设5–240分钟。

手动任务不参与 AI 重写。双击它可编辑；删除按钮会再次要求确认，删除会连同该任务的记录一起移除，默认取消。

未来任务不会出现在今日待办。到“周视图”选“独立任务”或对应计划，再跳到任务所在周。已完成的独立任务也能在周视图查看。

### 手动编辑，不使用模型

双击任务，修改名称、说明、预计用时、日期、提醒、状态或笔记，然后保存。修改日期仍须满足该计划的时间上限；批量改日期请看“补排与计划暂停”。

手动修改的任务默认禁止 AI 修改。已有学习记录或已复盘的任务也受保护；不要删除记录来强行解除保护。

### 用 AI 局部调整

在计划库选中计划，点击“AI 调整计划”。选择任务、当前计划周或剩余未完成部分，说明想怎么改，也可以选择“更具体”“降低难度”等快捷意图。

先看修改前后和原因，再整批确认。放弃预览不会改变原计划。如果只接受部分，缩小任务范围后重新预览。

要换整体目标、周数或学习日，用“按此计划创建副本”。原计划及其学习记录保留，新计划不会冒用旧的完成状态。

### 查看近7天的调整，或回到某次安排

在计划库选中计划，点击“历史与数据 → 调整历史与回溯”。左侧按保存顺序显示最近7天（滚动168小时）的调整及本机时间，精确到秒。

1. 选一条记录，再选“回到这次调整之后”或“回到这次调整之前”。创建计划之前没有可恢复的状态。
2. 右侧查看“当前”和“回溯后”的差异、保留原因，以及时间超限。
3. 点击“回溯到所选状态”，核对确认窗口，再点“确认回溯”。取消或关窗不改变安排。
4. 如产生新的时间超限，还会按日期、计划占用及超出分钟数再问一次；默认取消，明确选择“仍然保留安排”才应用。原时间上限不会被改大。

回溯只恢复任务内容、日期、提醒、保护锁和这份计划的名称、目标、排期、暂停或归档设置。**当前的完成状态、笔记、难度、人工补记、专注记录、复盘和提醒发送历史都保留；全局预算和其他计划不变。**

已复盘的学习任务保留现有内容和日期；历史里没有、但现在已有学习记录的任务不会被删除。历史里已删除的手动任务可以找回内容和日期，但不会用旧快照填回已删除的学习记录。这些例外会在预览中逐项说明；不能原地恢复的任务结构也会解释原因。

正在关联专注或休息时，先到专注页结束计时，再重新预览。预览后若有编辑、打卡、新专注记录、其他计划变更或预算修改，原预览失效，不会覆盖新变化。历史暂停若已经到期，不会因为回溯重新暂停，也不会补发旧提醒。

每次确认回溯前，软件另存本机备份，并将“回溯前的当前状态”和“回溯后的实际状态”一起保存为一条新的历史。想切回来，可选最新“回溯历史”的“调整之前”。后来的历史不会被抹掉，连续回溯也有记录；备份或保存失败则不应用。

从本次补丁开始，重命名、归档／恢复、任务内容／日期／提醒／锁定编辑、手动增删、补排、暂停／恢复、AI调整、复盘调整和回溯都会记录。普通打卡或每秒计时不单独生成安排版本。旧版未记录的操作无法补造，只能显示原来已有的历史。

窗口默认仅提供近7天历史回溯，不会因打开窗口而删除更旧的已有历史。“查看需求与历史”仍可只读查看已有问答、概略与记录。整库备份包含完整历史，单份计划JSON仍只导出当前计划及学习记录，不夹带其他计划或完整版本历史。

### 长标题与显示省略

长名称在左侧卡片中省略显示，悬停可看全文，右侧显示完整内容。想修改保存的名称，点击“计划管理 → 重命名计划”；界面省略不代表内容被删。

### 归档或删除计划

暂时不想继续学，先选计划，再点“归档／恢复”。归档会保留任务和学习记录；以后可以恢复。

确实不再需要这份计划时：

1. 在计划库选中它，点击“计划管理” → 危险操作下的“删除计划…”。
   菜单使用与其他下拉框一致的圆角浮层，点击外面或按 Esc 就能收起；点菜单项只打开确认窗口，不直接删除。
2. 核对完整计划名称、任务总数和已完成数量。
3. 在输入框原样输入“确认删除”四个字，不加空格。
4. 点击“删除这份计划”。只输入文字不会删除；按回车、Esc、取消或关闭窗口也不会删除。

删除后，这份计划、它的任务、学习记录、提醒和历史会移入回收站，30天内可在“历史与数据 → 回收站”恢复；其他计划、独立任务或模型配置不变。关联专注或休息尚未结束时，请先到专注页结束计时；确认期间又编辑或记录了学习进度，需要重新核对后再删除。

软件还会在每次删除前单独保存一份 `before-delete-plan-…sqlite3` 备份。备份失败时不会删除。误删后优先使用回收站；超过期限或安装补丁前已删除的资料，才需要查找旧备份。备份在数据目录的 `backups` 文件夹，它是整库备份，恢复整库会回退其他数据；不要直接覆盖当前数据库文件。

## 补排与计划暂停

### 指定一天：单项或批量改期

1. 在计划库选计划，点击“任务安排 → 调整排期”；也可在“今日 → 任务管理 → 安排逾期任务”打开。
2. 选择计划范围，勾选要移动的任务。只勾一项就是单独调整，多选就是批量调整；不会默认挪走其他任务。
3. 保持“指定日期”，选择目标日。可用“今天”“明天”“一周后”快捷按钮。
4. 点击“查看排期预览”，核对每项原日期和新日期、当天总用时。
5. 没有冲突后点击“确认应用”。取消或关窗不会改日期。

进行中、有笔记或已累计用时的任务，可以由你明确选择改日期，记录和 AI 锁定不变。正在关联专注或休息的任务须先结束计时；已完成、已复盘及归档任务保留历史日期，列表会写明原因。

目标日可以不是原来的学习日，但不能早于计划开始日或处在计划暂停期间；这些日期限制不能靠确认绕过。

如果只是超过这份计划的每日／每周时间上限，预览会显示“超限提醒 · 应用时需再次确认”，但仍可点“确认应用”。接着会弹出超限明细，默认取消；确定愿意这样安排时，点击“仍然保留安排”才保存。

“允许跨计划总预算超载”是对所有任务合计预算的选择，不等于已经确认了这份计划自己的上限。勾选后，应用时仍会再次询问。没有勾选且合计预算不足时，请先改日期或勾选该选项重新预览。

### 自动安排：帮你寻找空闲学习日

选择“自动安排”，再选起始日。软件按原任务顺序寻找各计划的学习日，默认保留已学习、已锁定和已复盘任务。

可明确勾选“本次允许移动手动锁定的未开始任务”，只改日期、不解除 AI 锁定。“同时顺延后续任务”会扩大移动范围，务必重新看预览。

最多寻找一年；放不下就显示冲突，不会删除任务、缩短内容或自动突破单计划时间上限。想明确集中到某天并确认超限，请使用“指定日期”。结束日可以延后，但原学习内容的周数不变。独立任务按每日总预算寻找日期，不受计划学习日限制。

### 暂停，不等于改期

在计划库点击“暂停计划”，选择“从这天继续学习”，查看说明后确认。

例如选择 **10月26日**：从今天起暂停，到10月25日晚上为止，**10月26日当天恢复**。

暂停只关闭这份计划的提醒和新专注入口，并把它从今日待办和活动预算中暂时排除。任务日期完全不变，仍可在计划库和周视图查看、编辑和记录。

如果已在计时，软件先问是否结束并保存，默认取消。到期自动恢复；当天没开软件，下次打开时恢复，不集中补发暂停期间的旧提醒。

### 提前恢复或重新安排任务

暂停后，原按钮变为“恢复学习”。点击并确认即可提前恢复，原日期不变。需要把未完成任务移到恢复之后，请再打开“调整排期”，选择任务和目标日。

恢复后如出现逾期标识，是因为日期仍在过去，不是数据丢失。可以保留原日期继续打卡，也可以按上面的步骤补排。

## 学习时间预算

### 设置全部任务合计的时间

在“设置 → 学习时间预算”给周一到周日分别设置分钟数。

- 不勾“设置预算”：当天不限制合计分钟。
- 勾选并设0分钟：当天不安排学习时间。
- 设60分钟：当天所有活动计划和独立任务的预计用时合计尽量不超过60分钟。

合计包含已完成任务的预计用时，表示当天安排过多少事；不是剩余时间，也不是实际专注时间。归档和暂停的计划不计入。筛选一份计划后，上方预算仍统计全部活动计划及独立任务。

### 超过预算时怎样保存

例如总预算60分钟，计划A占40分钟，计划B又新增30分钟：软件先不保存，显示日期、70/60分钟和各计划占用。

默认点“取消”，回去减少任务或换日期。确实愿意当天多安排，可点“仍然保留安排”，软件才保存。

补排时可勾选“允许跨计划总预算超载”再预览，应用时仍需确认。指定日期改期、手动添加／编辑，以及导入或撤销手动安排，如果新增加了单计划超限，也会询问一次。两种上限同时超出时，明细会一起列出。

确认窗口按日期或周次列出“预计安排、时间上限、超出”三项数字；超过每日总预算时，还会列出各计划占用。内容较多可以滚动查看。默认选择“返回调整”，不保存本次更改；明确点击“仍然保留安排”才会保存。按回车、Esc或关闭窗口不会代替你确认保存。

确认只针对这一次操作，不会关闭以后所有提醒，也不会改变原来的预算和计划上限。已有、已确认的超限不会因为补记笔记或用时反复询问；再次增加超限则要重新确认。AI生成／调整仍不能自动突破上限。

### 修改预算和恢复计划

改预算不会替你搬任务：原来排了90分钟，预算改成60分钟，原任务保留，并提示超出30分钟。

计划到期会照常恢复，不因预算不足卡住恢复，也不偷偷改期。恢复后与其他任务撞在一起，会显示超限，由你决定调整哪项。

看完预览后，如果又编辑、打卡、计时或改预算，旧预览就不能直接应用。请重新预览，让软件按最新资料检查一次。

## 记录与每周复盘

### 找到和记录任务

今日显示今天及逾期的未完成任务，不包含未来任务。右上角“按计划”可选全部、某份计划或独立任务；上方七日统计不随筛选改变。

双击任务填写状态、人工补记分钟、难度和笔记。实际用时＝自动专注＋人工补记，不要把同一段专注时间再手动填写一遍。

已记录专注的未开始任务会自动变成“进行中”。把鼠标停在状态文字上，会显示圆角“累计专注”卡片，例如“2 分 42 秒”；不满一小时不显示“0 小时”。卡片不挡点击，移开鼠标或开始其他操作会收起。这不代表任务已完成，完成后仍需自己标记。

### 逾期与延期不同

日期早于今天且未完成，会显示“逾期 N 天”和暖红色提醒。完成、改到今天或以后后，逾期提示消失；归档和暂停任务不标逾期。

“延期”是你手动填写的学习状态。“逾期”是软件按日期自动提醒，不会替你修改学习状态。周视图的逾期筛选只查当前显示周；更早任务要切换周次。

### 周历与明细表

周视图从周一到周日显示真实日期，可切换“七日周历／明细表”。点击任务看说明和产出，双击编辑，点“开始专注”直接计时。

没有看到任务时，先看顶部说明：可能日期不在所选计划范围内，或筛选隐藏了任务。可点“跳到计划首周”“跳到下一项未完成任务”或“清除筛选”。这些按钮只改变显示，不改任务日期。

“任务累计实际”统计当前这些任务过去累计的用时，不表示全部发生在本周。提醒时间只是通知时间，不是学习开始时间。

### 每周复盘

把原计划这一周的任务都标为“已完成”或“延期”，再点“AI 辅助 → 生成本周复盘”，按周顺序进行。手动添加任务不占用原计划周次，也不替代原来的学习日。

复盘先预览再应用，会保留受保护任务。已复盘周次可补记用时和笔记，但不能重写原任务或状态。复盘属于模型请求，可能使用额度。

## 专注与提醒

### 从任务开始计时

任务旁点击“开始专注”，自动进入专注页并关联正确任务。新的一轮按任务的预计用时开始：例如任务预计45分钟，就从45:00倒计时；预计240分钟也会完整计时，不截成25分钟或180分钟。专注页的“专注分钟”会同步显示该时长，休息分钟仍沿用你的设置。

任务以前积累过用时，不会从这次倒计时中扣掉；累计用时与新一轮计时是两回事。在专注页选好任务再点“开始／继续”，新一轮也按任务预计用时开始。

同一任务计时中只跳转；暂停时继续，不清零。切换其他任务前先问是否保存并结束旧计时，默认取消。已完成、归档或暂停任务不能开始新专注。

### 用时如何累计

不关联任务时，专注分钟可自行设置，初始25分钟；任务启动会将专注页分钟数同步为该任务预计用时。休息初始5分钟，可自行调整。实际产生专注用时后，“未开始”自动变成“进行中”；延期和已完成状态不会因此改写。

用时约每5秒落库，暂停或结束时补记剩余秒数，不重复累计。休息不算专注。完成一轮不会自动完成任务；休眠或退出后暂停，重启要自己继续。

### 提醒何时出现

任务可启用提醒，建议时间20:00，也可修改或关闭。只有软件运行中（包括托盘）且 Windows 允许通知时，才会弹出提醒。退出或关机时不能弹出；错过的提醒会汇总，暂停期间的旧提醒不补发。

设置或托盘可暂停所有提醒，开机启动默认关闭。

## 统计、子任务与周期复习

### 查看统计与离线总结

在「今日 → 学习工具 → 学习统计」，选择近7天、近30天，或自己设置日期。可以查看全部任务、独立任务或某份计划；归档计划需勾选后才计入。

默认的「每日用时对照」一行对应一个日期，每行两条横向用时条：浅蓝描边的「计划」是预计分钟数，实心蓝的「已记录」是专注计时加人工补记。右侧直接写分钟数，所有日期共用同一刻度，条越长表示用时越多。没有记录会写「未记用时」，没有任务会写「没有任务」，不必靠颜色猜。日期多时向下滚动，不把多天揉成一根柱子。

这里的日期是**任务安排在哪一天**。表格显示这些任务目前的完成数、预计用时和累计实际用时，包含专注和人工补记。它不是当天实际发生的学习时长，也不能还原过去某天的完成率；改期或补记后会随当前记录更新。暂停计划仍计入统计，避免暂停后历史突然消失。

下方总结只按本机数据生成，不调用模型、不收费。可以点「复制离线总结」保存到自己的笔记。已完成但没有记录用时，不代表真正只花了零分钟。

### 分组与执行步骤有什么用

这两个功能都可不填。不需要拆分时，直接按原任务学习和打卡即可。

**任务分组（原“阶段”）像文件夹**：例如把“运行代码、变量输入”归入“基础练习”，把“制作工具”归入“项目练习”。它帮助看清任务属于哪一部分，不改变任务日期、原学习周次或用时。

**执行步骤（原“子任务”）是某项任务里面的小清单**：例如“运行第一段代码”可拆成“打开示例 → 运行代码 → 修改输入再运行”。每一步可勾选，用来记住做到哪了，不会另算任务时长。示例只是说明，不会自动添加到你的任务里。

1. 在计划库选计划，点「任务安排 → 任务分组与执行步骤」。选中一个或多个任务，填写分组名，再点「分配给选中任务」；留空会取消分组。
2. 双击一项具体任务或点「管理执行步骤」，逐条添加。今日也可从「学习工具 → 选中任务的执行步骤」进入；各页双击任务打开编辑窗口后，也有「任务分组与执行步骤」入口。
3. 窗口顶部的“当前任务”与“当前状态”说明正在编辑谁。分组下拉的“未分组”表示不归入任何组；也可直接输入新分组名称。勾选表示这一步已经做过，点「保存分组和步骤」才保存。步骤不另计时，有勾选的“未开始”任务会推进到“进行中”，但绝不自动标为完成；整体做完后仍需在任务详情里确认完成。
4. 只分组、添加或修改未勾选的步骤，不会改变原任务状态。原来已经完成的任务也不会因为添加新步骤而自动退回未完成；任务状态与步骤进度分开显示。例如“已完成、0/2步”表示原任务已完成，而新加的两步还没勾选，并不是分组替你完成了任务。
5. 双击步骤文字可修改，移除步骤需确认。每项任务最多40步，每步最多120字；分组名最多40字。已复盘的任务只能勾选现有步骤，不能改步骤内容或分组。分组列表下方会显示当前选中的任务，多选可批量分组，管理步骤需只选一项。

分组列表上方默认仅搜索任务名称。切到“全部内容”可搜索具体说明、完成标准或安排日期，并在每项结果下显示匹配字段和片段；多词/日期写法与其他页一致。灰色文字显示匹配数，清除键恢复全部任务。搜索不改日期、分组或记录；原来选中但被搜索隐藏的任务会取消选择，批量分组只处理当前看得见且已选中的任务。

阶段和步骤内容会记入计划调整历史；只打卡不会刷安排历史。回溯保留当前勾选状态，已经打卡的步骤不会因回溯被删。旧历史没有步骤时不会伪造旧打卡；恢复已删除任务的步骤不冒用旧记录。

### 创建周期任务或复习

1. 在「今日 → 学习工具 → 周期任务与复习」，选择加入某份未归档计划或作为独立任务。
2. 填写名称和每次预计分钟，也可填写具体说明、完成标准；选择「每天一次」「每周选定的星期」或「间隔复习」。开始、结束日期都包含当天，最长一年。
3. 间隔复习填写相对开始日期的天数，例如`1,3,7,14`表示开始后的第1、3、7、14天；`0`表示开始当天。这只是可调整的安排，不保证学习效果。晚于结束日期的间隔不生成。
4. 点「查看预览」，检查每次日期和全部活动任务负荷，再点「保存这些任务」。新的日/周/总预算超限会单独列出，默认返回调整，明确确认才保存。保存后每次都有独立任务ID，使用原来的打卡、提醒、专注和改期功能。

这是一次创建到结束日期的有限安排，**不是后台永远生成**。漏做保留在原日期，不自动覆盖或堆到下一次；结束日之后要继续，需要重新创建。重复点击保存不会重复生成；重新创建相同规则则被视为你明确创建另一组任务，请先查看已有周期。

### 停止、修改周期安排

点「已保存的周期」，选一条后点「停止后续安排…」。先查看将移除的实例和保留原因，再确认。只移除今天起未开始、没有学习记录、没有正在专注的任务；过去、有记录和正在专注的任务保留，提醒也随移除的任务取消。

改规则可先停止旧规则，再新建；只想改某几天，用「调整排期」选这些实例即可。停止后不自动重建已删实例，安排历史回溯也不会重新激活周期规则。规则、实例、步骤和阶段进入整库备份；所属计划的JSON也包含相关内容，独立任务仍需整库备份。

本版使用schema7/计划JSON6，支持旧库与旧计划。旧程序不能打开新库；回退请用升级前备份。

## 回收站与恢复

### 误删后怎么找回

在计划库点击“历史与数据 → 回收站”。即使没有普通计划，也能从固定“独立任务”箱进入。

1. 按名称搜索并选择已删除的计划或手动任务。“恢复截止”是还能找回它的最后时间，不是任务要安排在哪天；列表时间按电脑本地时间显示。
2. 单项手动任务默认“按原日期恢复”。想换一天，选“指定安排日期”，再选下方的日期。整份计划仍按原排期恢复，如需批量改期，请恢复后使用“调整排期”。
3. 查看下方恢复预览，核对原日期→新日期、任务数量、学习记录和时间占用。指定日期不能早于所属计划的开始日，也不能落在该计划暂停期间；不合适时会直接说明原因。
4. 点击“恢复选中项目”，核对后选“确认恢复”。默认取消。新增时间超限时，还要另行确认“仍然保留安排”；取消不会恢复一半，也不会改变回收站快照。

恢复会找回原ID、任务内容、状态、笔记、用时、步骤和提醒发送记录。默认恢复原日期；单项任务只有你明确指定新日期才会改期。改期只改变安排日，已有学习记录不丢失；按安排日期汇总的统计会归入新日期。计划的排期、暂停资料和调整历史也一并保留。不改其他计划，不恢复模型配置，不调用模型。原提醒发送历史保留；改期后的提醒按新日期去重，仍遵守暂停规则。单次周期任务的安排日可以改变，但不会改动原周期规则或重新开启停止的规则。

### 双击查看删除时的详情

左键双击回收站项目，或选中后点击“查看详情”，即可打开独立的只读窗口。可查看原任务的完整说明、完成标准、原日期、状态、预计用时、累计专注、人工补记、实际总用时、难度、笔记、提醒、分组和执行步骤。双击整份计划会显示计划说明和所含任务详情。

详情展示的是删除时的快照，不是当前计划库中的同名任务；打开、关闭或重开都不会恢复任务、修改记录、消耗模型额度或延长恢复期限。过期但尚未彻底删除的项目也可以查看详情。

同名但不同ID的计划可以同时存在，不会被替换。同一ID的计划或任务已存在时，恢复会被阻止，以免覆盖新内容。手动任务原来属于某计划而该计划也被删除时，请先恢复所属计划，再恢复任务。恢复单次周期任务不会重新开启已停止的规则。

预览后若任务、学习记录、其他计划或预算有变化，请重新查看预览，不会覆盖后来保存的数据。

### 可恢复期限与彻底删除

删除后的30天内可以恢复，以列表截止时间为准；到达截止时间即过期。勾选“查看已过期”可以查找过期项目，但不能直接恢复。

程序不会偷偷清空快照。要清除时，选择项目，点击“彻底删除…”，输入“彻底删除”四个字，再点确认；按回车、Esc或取消都不会清除。彻底删除后不能在回收站撤销。整库备份独立保留，不会随着清空回收站删除；需要查找更早资料时先咨询恢复方式，不要直接覆盖当前数据库。

回收站只接收此补丁安装后，通过“删除计划”或“删除手动任务”明确删除的项目。停止周期生成、历史回溯和AI调整不属于回收站删除。安装前已删除的资料不会凭空出现，仍需删除前备份。整库备份包含回收站，单计划JSON不包含回收站。新数据库结构为schema7，旧程序不能直接打开；回退程序应使用升级前备份。

## 数据与备份

### 保存在哪里

数据在 `%LOCALAPPDATA%\LearningCompass`，不在安装目录。正常升级或卸载保留数据；请不要手动删除这个目录。

### 备份和恢复有什么区别

- **导出计划 JSON**：保存一份计划及其任务、记录和需求。导入时新建副本，不覆盖原计划。计划内手动任务一起导出；独立任务请用整库备份保存。
- **立即备份**：保存整个学习数据库，包括独立任务、草稿、历史、预算和暂停信息。不包含 Key。
- **恢复备份**：将当前整个数据库换成备份里的资料，不是合并。先看摘要，确认需要回到那个时间点再恢复。恢复前会另存当前资料。

每天首次修改前自动备份，保留最近30个每日备份。数据库升级也先备份，在临时副本中校验成功后才替换原文件。旧 JSON 和旧数据库仍可导入，源文件不被修改。

本版使用 schema7，支持 schema1–6 的旧备份；计划 JSON6 继续接受旧格式。旧程序（包括公开版2026.10.11）打不开新结构，回退时必须使用对应旧构建及升级前备份，不能直接让旧程序读写新库。

换电脑后需要重新填写 Key。备份有个人学习内容，请妥善保管。归档保留记录；删除需确认。

## 常见问题

### 连接失败、一直等待或超时

先点“复制连接诊断”，保留这次失败的操作、HTTP、阶段和类别，不必为了补诊断重新发送。

检查当前连接地址、模型 ID、代理和电脑时间。证书必须受系统信任；软件不会关闭 TLS 检查。如果自行配置 `SSL_CERT_FILE`／`SSL_CERT_DIR`，还需核对指定证书位置。

模型列表失败不一定代表生成不可用，可手动填 ID。服务状态正常也不保证你的请求成功，不能把历史故障当作每次失败原因。

### 测试成功，创建却提示 HTTP400／422

简单连接测试的 JSON 比创建所需结构简单，所以可能测试通过、创建被拒绝。这通常是参数或格式兼容问题，不一定是 Key 错。

1. 复制“需求与概略”或实际失败操作的诊断，不要用成功的连接测试代替。
2. 检查接口、JSON 格式及输出上限字段是否符合服务商要求。若诊断明确指向 Schema，可手动改为 JSON 模式，不要同时乱改 Key 和地址。
3. 修改连接后，在顶部选好它，回草稿点“换用顶部模型”，再发送。新请求可能计费。

### HTTP200，但结果未通过本地校验

200表示服务响应了，不保证内容符合格式、字数、任务数量或时间要求。软件最多修正一次，仍不合格就保留草稿，不存成正式计划。

诊断会指出字段和计数，例如 `outlines[0].points[0].summary` 表示概略第一点的摘要。过长摘要可能显示摘录，完整原文保存在展开详情；不会为缩短显示而删除详情。无法完整保留时仍拒绝结果。

不用为了模型的格式错误修改自己的学习目标，也不要把 Key、模型原文、原始请求或服务错误全文发给别人。发送脱敏诊断即可。

### 密钥无效或余额不足

到对应服务商平台检查 Key、权限和余额，确认当前软件配置使用的就是那一家服务。不要把不同平台的 Key 混用。

### 不能改期、保存或撤销

看任务旁或预览中的具体原因：是否已完成、已复盘、仍在专注、日期处于暂停期间，或超过时间上限。只想改日期时用“调整排期 → 指定日期”，不必让 AI 重写整个计划。

提示资料已变化时，重新预览即可。不要删掉笔记和学习记录来绕过保护。手动指定日期和添加／编辑任务的时间超限可再次确认；自动安排和AI不自行突破上限，已完成／已复盘／正在关联专注等保护也不会因此失效。

### 任务找不到

今日不显示未来或已完成任务。去周视图清除筛选，再跳到任务所在周。暂停计划不显示在今日；独立任务要在计划筛选中选“独立任务”或“全部计划”。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe run_desktop.py
.\.venv\Scripts\python.exe -m pytest -q
```

交付测试包前，先把程序VERSION与本指南版本同步为四段，例如 `2026.10.12.1`。测试次数对应实际交付，不是自动测试运行次数；当前三段可用号会被测试构建拒绝。

.\.venv\Scripts\python.exe scripts/build_desktop.py --local-test
