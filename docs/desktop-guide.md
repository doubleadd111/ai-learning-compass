# 学习罗盘 2026.10 桌面版使用指南

适用 Windows 10／11 x64。版本号 `2026.10.0`。

## 安装与打开

下载 `LearningCompass-2026.10.0-windows-x64-setup.exe` 并运行，安装到当前用户，无需 Python、命令行或管理员权限。也可以解压 portable.zip 后打开 `LearningCompass.exe`；请保留整个文件夹，包括 `_internal` 中的运行库。安装包尚未代码签名，可用同版本 SHA256SUMS.txt 核对下载文件。

关闭窗口默认进入右下角系统托盘，提醒和专注仍会继续。托盘菜单可打开窗口、暂停提醒或完全退出。开机启动默认关闭，可在设置中自行启用。

## 接入自己的模型

2026.10.1 本机测试版：连接测试最多等待 30 秒，模型列表最多等待 15 秒，生成／复盘最多等待 240 秒；取消立即恢复界面。测试构建覆盖现有本机程序后，标题栏会显示 2026.10.1。尚未发布新的正式安装包，GitHub 的 2026.10.0 不包含此修复。

在“设置 → 模型连接”添加配置：选择 DeepSeek、OpenAI 或自定义服务，填写服务地址、模型 ID 和自己的 API Key。同一服务商可以添加多套配置。顶部模型框选择下一次生成所用的连接。

- DeepSeek 模板预填服务地址和模型名；以服务商当前可用名称为准。
- 兼容服务通常使用 Chat Completions 和 JSON 模式。支持严格结构化输出时，可以选 JSON Schema。Responses 服务则选 Responses 接口。
- Chat 的输出上限参数默认 `max_tokens`；某些模型要求 `max_completion_tokens`，可在设置中修改。
- 模型列表可获取，也可手动填写。连接测试会发送小型真实请求并消耗额度；生成和复盘调整同样使用服务商额度。
- 密钥默认交给 Windows 凭据管理器保存。选择“仅本次”或系统凭据不可用时，密钥只留在当前进程，下次打开需重新填写。删除连接会移除该连接的凭据。

不支持 Claude／Gemini 原生接口；若服务商为这些模型提供兼容接口，可按兼容方式配置。程序不承诺所有模型都能生成有效计划。连续两次结果不合规时，会提示缩短周期或更换模型。

## 日常学习

1. 创建计划：选择科目、目标、基础、1–8 周、开始日期、每周学习日和每日上限。
2. “今日”看今天与逾期任务，“周视图”看实际排期，“计划库”搜索和管理多份计划。
3. 双击任务，编辑内容、日期和提醒，记录完成情况、人工补记用时、难度和笔记。更改日期仍会检查单日与每周时间上限。
4. 每周任务全部标为已完成或延期后，生成复盘。先查看预览再应用；已开始或手动编辑的未来任务保留。延期任务需要下一周有空位，否则提示先安排任务。
5. 应用后可以撤销最近一次调整。若之后已新增记录或改动，不能直接撤销，以保留新记录。已复盘周次可补记用时和笔记，但不能改写任务或状态。

“专注”默认 25 分钟／休息 5 分钟，可改时长、关联任务、暂停和结束。专注用时自动累计，人工补记另外累加。完成计时不会自动完成任务。电脑休眠或完全退出时暂停；重启后手动继续。

提醒只在软件运行（含托盘）且 Windows 允许通知时显示；错过的任务集中提醒。完全退出或关机期间不能弹出提醒。

## 数据、旧版迁移和备份

桌面版固定使用 `%LOCALAPPDATA%\LearningCompass`，不依赖源码目录，也不存进安装目录。升级或卸载程序会保留该目录。设置中可以打开目录；彻底删除资料前建议先备份。

- 首次可直接载入不消耗 API 的样例；旧版资料在“设置 → 数据与备份”导入。
- 旧版 `plans.sqlite3` 只读导入，源文件不改动；选择开始日期后按原每周天数安排日期，之后可逐项改期。
- 旧版 JSON 和新版计划 JSON 均可导入，导入为新计划；新版保留已有日期。
- 每天第一次数据变更前自动备份，保留最近 30 个每日备份。“立即备份”创建额外手动备份；恢复前再创建恢复点。
- 整库恢复先显示计划、任务和连接数量，然后替换当前资料。单份计划 JSON 用于交换，整库 SQLite 备份用于迁移或恢复全部资料。
- API Key 不在数据库、JSON 或备份中，换电脑后需重新输入。普通备份包含你的学习内容，请按个人资料保存。

## 从源码运行与构建

在项目目录用 Python 3.12 创建虚拟环境，然后运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe run_desktop.py
```

测试使用 `python -m pytest -q`。构建安装包需要 Inno Setup 6.7 或更新版本：

```powershell
.\.venv\Scripts\python.exe scripts/build_desktop.py --iscc '你的 Inno Setup 目录\ISCC.exe'
```

产物在 `release/`。PyInstaller 使用目录模式，保留可替换的 Qt 动态库；仅打包桌面入口需要的模块，不包含 `.env`、个人数据、测试或 Streamlit。`build-manifest.json` 和 `SHA256SUMS.txt` 记录版本与校验值。第三方声明见安装包内的 THIRD_PARTY_NOTICES.md 和 licenses/。
