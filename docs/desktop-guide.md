# 学习罗盘桌面版使用指南

适用 Windows 10／11 x64，版本 **`2026.10.9` 本机测试版**。

本指南与软件一起更新，无需联网查看。公开下载仍为2026.10.0，后续测试补丁尚未正式发布。

## 首次体验

1. 双击 LearningCompass.exe。无需 Python 或 PowerShell；便携版需要保留整个文件夹，包括 `_internal`。
2. 在“今日”载入两周 Python 体验样例，不需要 API Key，也不会使用模型额度。
3. 到“计划库”选择样例，双击任务记录进度；“周视图”按真实日期查看安排。
4. 想生成自己的计划，先到“设置 → 模型连接”添加服务，再按“创建计划”。

### 打开与找回使用指南

侧栏“使用指南”或 F1 打开同一个独立窗口，可以边看边操作。指南在任务栏的学习罗盘图标组中有独立缩略图，也可以通过 Alt+Tab 切换。

指南最小化后，再按 F1 或点击“使用指南”即可恢复。普通打开保留当前章节；创建与修改窗口的“查看本步骤说明”会直达相关章节。搜索框会筛选含关键词的章节。

### 使用下拉选项

下拉列表中，浅色背景和右侧勾标识当前已选项；鼠标悬停只预览高亮，不立即更改设置。点击选项或用上下方向键后按 Enter 确认，按 Esc 放弃。长列表可以滚动，名称过长时省略显示，悬停可查看完整文字。明暗主题会同步更新。

### 退出软件

关窗默认进入系统托盘，并非完全退出。右下角托盘图标右键 → “完全退出”才能停止软件。覆盖更新前请完全退出。首次打开可能较慢，不要连续双击启动多个实例。

## 接入自己的模型

在“设置 → 模型连接”添加 DeepSeek、OpenAI 或自定义 OpenAI 兼容服务，填写配置名称、服务地址、模型 ID 和自己的 API Key。顶部模型框影响新的计划流程；已保存的草稿使用自己绑定的模型，可以在草稿中明确切换。

### 配置与费用

- 模型 ID 以服务商提供的名称为准，可获取模型列表或手动填写。
- 选择服务支持的 Responses／Chat Completions 接口，以及 JSON Schema／JSON 模式。不支持 Claude／Gemini 原生接口，但可使用服务商提供的兼容接口。
- Chat 输出上限默认 max_tokens，某些模型需要 max_completion_tokens。
- API Key 默认保存在 Windows 凭据管理器；仅本次使用的密钥在退出后消失。密钥不会放进学习数据库、导出或日志。
- 测试连接是真实小额请求，最多等30秒；模型列表15秒；生成和调整每次请求最多240秒。请求旁显示倒计时，可以随时取消。
- 问答、概略、每日任务和修改方案是不同阶段，每次点击发送都可能消耗额度；打开指南、展开概略和手动编辑不会调用模型。

切换服务商时必须使用对应服务商的 Key，不要把密钥填进学习目标、问答、笔记或服务地址。服务地址中禁止密码和查询参数。

### 路由与故障诊断

连接高级设置默认保持“默认代理”；只有明确选择“直连”才绕过环境代理。软件不会失败后偷偷切换路由，也不会关闭TLS证书校验。

默认信任 Windows 系统证书与公共根证书；企业或代理使用的证书必须已被系统信任。若自行设置了 `SSL_CERT_FILE`／`SSL_CERT_DIR`，以指定的证书策略为准。出现证书错误时检查时间、代理或安全软件，不要通过关闭验证来绕过。

网络请求结束后可点击“复制连接诊断”。摘要包含操作、阶段、耗时、HTTP状态、故障类别和异常类型，不含Key、认证头或学习内容。

“获取模型列表”失败不一定代表生成接口不可用。可以手动填写模型ID，但不能把匿名可达或收到HTTP响应当作真实生成成功。

## 创建学习计划

创建窗口将资料分为科目与目标、当前基础、预期产出、开始日期与周期、学习日与时间、偏好和限制。周期1–8周，每周1–7天，每日可用时间15–240分钟。

### 安全调整数值与选择

所有下拉选择框、数值、日期和提醒时间，只有鼠标位于方框最右侧的箭头区域内时，滚轮才切换选项或调整数值。停在文字、数字或框内其他位置滚动，不会改值，长表单仍可正常上下滚动。覆盖学习科目/基础、模型选择与配置、追问、筛选、状态/难度、日历月份等入口。

下拉列表展开后，可以在列表内正常滚动浏览，不会仅因滚轮就提交新选项；请点击所需选项或用键盘确认。直接输入、点击箭头、键盘方向键和日期日历点选仍按原方式使用；这里只限制滚轮的触发范围，不限制鼠标点击范围。

### 选择日期

可以直接输入 `YYYY-MM-DD`，也可以点击日期右侧箭头打开日历。日历从周一开始；蓝底是选中日期，小圆点标记今天，淡色数字属于相邻月份。

- 左右箭头切换月份；点击月份列表可跳月。年份可直接输入四位数字，离开输入框后跳转；无效年份恢复原值。
- 点击具体日期，或用方向键移动后按 Enter 确认。仅翻月不会更改日期；按 Esc 关闭并恢复打开时的日期。
- “今天”直接选取今天。任务编辑若设有日期范围，范围外日期不能选取，不会绕过计划时间校验。

### 从资料到正式计划

1. 填好资料，保留默认引导流程，或勾选“快速生成”。快速模式跳过追问，但不跳过概略确认。
2. 引导模式只补问关键缺口，最多2轮，每轮1–3题。可选参考答案，也可自由输入、“不确定”或跳过。
3. “概略确认”按先后顺序显示3–5张阶段卡片，摘要共80–140字。卡片内点“查看安排与产出”展开阶段目标、内容、产出与依据，再点“收起详情”折叠；这些操作不消耗额度。顶部展示已确认的周期和时间，底部集中列出需要核对的前提。
4. 方向不满意，可点对应卡片右侧“修改”补充意见，或返回资料重新填写。“修改”会带着该点意见发送模型请求，可能使用额度，变化后需要重新确认概略。
5. 点“确认概略，生成每日任务”，再检查每天的任务、时长和产出。只有点“保存计划”后才成为正式计划。

草稿会自动保存在本机；关闭窗口或重启后，可从“继续草稿”接着做。草稿只在明确点击发送时提交给所选模型；失败、取消和超时不保存为正式计划。可删除不需要的草稿。

### 继续草稿与时间

草稿列表右侧显示创建时间和最后修改时间，精确到年月日时分，按本机时区显示。只有资料、回答、模型结果或状态实际变化才更新修改时间；浏览、打开或无变化保存不刷新时间。

旧版没有记录的创建时间显示“旧版未记录”，不会把升级时间伪装成创建时间。

## 修改与保护计划

### 手动修改

双击任务可编辑内容、预计时长、日期、提醒和学习记录，无需模型、断网也能用。仍会检查单日和每周时间上限。

### AI 调整计划

在计划库选择计划，再选择选中任务／当前计划周／剩余未完成部分。

可使用“更具体”“降低难度”“增加练习”“缩短任务用时”“重新安排日期”，也可输入自己的想法。信息不明确时可追问，次数与创建流程相同。

先看差异预览，包括每项修改前后、修改原因、日期和时长。点“应用全部修改”才写入；放弃预览不改变原计划。只接受一部分时，缩小范围重新生成预览，不混合不完整的方案。

### 保护规则

已完成、进行中、有用时／笔记／难度记录、已复盘周次不能由 AI 改写。

手动修改的未开始任务默认“禁止 AI 修改”，可在任务窗口明确解锁；不能解锁已有学习记录的保护。周复盘使用同样规则。

局部调整保留原任务 ID，不新增或删除学习日。“更具体”先细化原任务内的操作步骤，不增加独立打卡子任务。AI 改期只能使用原周期的可用学习日；没有足够空间会提示冲突，不能偷偷提高时间上限。

### 大改创建副本

变更整体目标、周期、每周学习日或每日可用上限，请选“按此计划创建副本”。

已学内容作为背景，旧记录仍在旧计划；新计划不伪造已完成状态。保存时“同时归档旧计划”默认勾选，可以取消。

每次 AI 修改保留版本，可查看历史。仅最近一次、且之后没有新学习记录或编辑的调整能够直接撤销；否则不覆盖当前进度。预览期间计划发生变化，也必须重新预览。

## 记录与每周复盘

### 每日记录

“今日”的任务列表右上方可“按计划”筛选：默认“全部任务”，选择计划后仅显示该计划的任务。筛选不会改动任务或学习记录，上方七日轨迹和统计仍是所有未归档计划的汇总。

这里的“全部任务”仍指今天及逾期的未完成任务，不包含未来、已完成或已归档任务。没有匹配项时会显示提示；未来任务请到计划库或周视图查看。重命名计划后保留筛选，所选计划归档或删除后自动回到全部任务。

双击任务可记录完成情况、实际补记分钟、难度和笔记。实际用时是自动专注时间加人工补记，避免把同一段时间再补记一次。

### 七日周历与明细表

“周视图”按周一至周日展示真实日期，今天以边线突出。每天直接显示任务、所属计划、预计时长、完成状态和“开始专注”。没有任务时显示“无安排”。

- 点击任务查看具体做法和产出；双击或点击底部按钮填写记录与编辑。
- 顶部可按计划、科目、状态筛选，切换“七日周历／明细表”；两种视图共用筛选和选中任务。
- 日期过多或窗口较小时可滚动，不会隐藏任务。上一周／本周／下一周可查看历史和后续排期。
- “任务累计实际”是这些排期任务累计的专注加补记，不表示用时都发生在本周。软件不虚构具体开始时刻，不把提醒时间当成开始时间。

### 每周复盘

每个计划周的任务均标为“已完成”或“延期”后，可生成本周复盘；按顺序逐周进行。

预览后应用，已开始或锁定的未来任务保留，延期优先但不能超出时间。已复盘周次可以补记笔记和用时，不能改写任务和状态。

“查看需求与历史”能查看创建时的问答、概略及修改记录。旧版计划没有的创建问答不会编造补齐，仍能继续学习和使用调整功能。

## 专注与提醒

### 从任务直接开始

今日、计划库和周视图的任务旁均有“开始专注”。点击后自动进入专注页、关联该任务并按现有专注设置开始；不会使用任务预计时长重置设置，也不自动标记任务完成。

同一任务运行时只跳转，暂停时继续；若正在为其他任务计时或处于休息阶段，会先询问是否保存旧用时并切换，默认取消。已完成或已归档任务的按钮禁用。

### 计时与记录

专注默认25分钟、休息5分钟，可修改、关联任务、暂停、继续和结束。自动累计专注用时，计时结束后由用户决定是否标记任务完成。休眠或完全退出会暂停；重启后手动继续。

### 提醒

任务默认建议20:00提醒，可修改或关闭。通知只在软件运行（含托盘）且Windows允许通知时显示；关机、退出时不能弹出，错过的提醒会汇总。

可在设置或托盘暂停提醒，开机启动默认关闭。

## 数据与备份

数据固定保存到 `%LOCALAPPDATA%\LearningCompass`，与安装目录分离，升级和正常卸载不会删除。设置 → 数据与备份可打开目录、立即备份或恢复。

- 每天首次修改前自动备份，保留最近30个每日备份。数据库升级和恢复前另建恢复点。
- 旧版 SQLite 与 JSON 只读导入，不改变源文件；导入为新计划。新版保留日期和进度，旧版缺日程时由用户补开始日期。
- 新版计划 JSON 包含当前计划、记录、需求和概略；旧JSON仍能导入。完整版本历史与草稿放在整库SQLite备份中。
- 整库恢复先显示摘要、确认后替换当前资料；旧备份会在临时副本上迁移校验，源文件不变。
- 当前数据库schema3，继续接受schema1／2旧备份。回退旧程序时不能让旧程序直接写新库；应保留新数据，并使用对应的升级前备份。
- 备份和草稿包含个人学习内容，请妥善保存；它们不包含 API Key，换电脑后需要重新填写。
- 归档保留全部记录；删除计划需要确认。修改预览或恢复历史不能跨越新的学习记录直接覆盖。

## 常见问题

### HTTP200但结果未通过本地校验

HTTP200表示服务已经响应，不代表返回的内容一定符合学习计划规则。这不要求立即更换Key，也不要为模型的格式错误改掉学习目标。

1. 9版会在错误弹窗和“复制连接诊断”的“本地校验”中显示具体字段、规则及必要字数/数量，例如“概略摘要合计：当前150、最多140”；这是示例，不是对某次错误原因的推测。
2. 字段说明：`questions`为追问，`options`为选项，`outlines`是模型传输中的概略数组，`points`为概略各点，`summary`为每点摘要；草稿内部仍沿用旧格式。
3. 缺字段、类型错误或无效JSON属于模型输出格式问题；空输出也可能是截断，不能仅凭空内容判断网络或Key失效。软件最多自动修正一次，仍失败就保留草稿，不保存为正式计划。
4. 若提示追问上限或重复问题，模型需要根据已有答案给出概略，不能无限提问；80–140字仅计各点摘要，不包含展开详情。9版本机补丁 A 遇到过长摘要时显示约100字的原文摘录，并明确提示全文已保留在展开内容中。点卡片内“查看安排与产出”即可阅读全文，不会额外调用模型。
5. 先复制本次失败的诊断再反馈，不用为了补诊断重复发送。可以继续草稿，也可以明确选择其他模型；每次新请求可能使用额度。不要发送Key、模型原文或原始服务错误。

摘录只改变展示标题，不删减原文或降低任务时间约束。若完整摘要和原内容合并后超过详情上限，软件不会截掉详情；仍按原规则校验，失败时保留草稿。无需为模型摘要过长而修改学习目标。

连接诊断只显示固定规则、白名单字段路径和计数，不记录模型原文；确认后的概略及展开详情属于本机草稿内容。并非所有失败都能由更换模型或缩短需求解决；如果尚缺证据，不会把某个猜测当作确定根因。

### 创建计划参数错误

如果“测试连接”成功，创建计划却提示“服务地址、模型名或接口参数不受支持”，不要立即更换Key或反复点击生成。连接测试只有简单JSON，创建问答、概略和修改使用的结构更复杂，服务可能接受前者而拒绝后者。

1. 先确认软件版本为2026.10.8或之后的修复版。7版真实反馈中，DeepSeek在“需求与概略”阶段拒绝了联合类型结构；8版严格模式使用无可空联合的问答传输，收到后转换回原草稿格式，不需要重建草稿。完整的时间、数量和字段要求仍由本机校验。
2. 打开“计划库 → 继续草稿”接着做，不需要删除计划或重新输入全部资料。若仍失败，先复制这次失败的诊断；创建概略通常对应“需求与概略”，不能用“JSON连接测试 / HTTP200 / success”代替失败信息。
3. 如果诊断为HTTP400/422并指向`invalid_json_schema`、`json_schema`、联合类型（anyOf）或输出格式，先保留诊断；如需绕过服务的严格结构限制，可到“设置 → 模型连接 → 编辑”，手动将“严格JSON Schema”改为“JSON模式”。不要同时随意改动地址、Key或网络路由。程序不自动切换格式，JSON模式仍执行本地校验。
4. 返回草稿，先在主窗口顶部选中修改后的连接，再点击“换用顶部模型”。草稿保留配置快照，设置改变后必须明确重新绑定，避免把新凭据发到旧地址。然后再次发送；这会使用模型额度，程序不会替你自动重试另一种接口。
5. HTTP404应核对模型ID、服务地址和接口类型；其他400/422应核对诊断中的参数类别，例如Chat服务要求`max_tokens`还是`max_completion_tokens`。以服务商说明为准，不要为了参数错误关闭证书校验。

提交问题时附上“操作、HTTP、接口/输出格式、服务错误码和参数类别”，不要发送Key、原始请求正文或完整服务错误正文。程序只复制白名单诊断，失败不会把半成品保存成正式计划。

结构化接口只支持各自的Schema子集，JSON模式也不代替本地校验；可参考[OpenAI官方结构化输出说明](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)。DeepSeek的地址、模型和Responses兼容范围见[DeepSeek官方说明](https://api-docs.deepseek.com/guides/responses_api/)。软件不会据此偷偷切换服务商或模型。

**HTTP200却没有结果？** 只代表收到响应头，不等于JSON生成成功。可以检查服务商状态、网络与代理；DeepSeek官方状态页：https://status.deepseek.com/ 。历史故障不能作为每次失败的固定原因，不要反复发送付费测试。

**提示密钥无效／余额不足？** 检查当前模型配置的服务地址、模型名、Key权限和对应平台余额。ChatGPT网页会员不等于API额度。

**结果连续两次格式错误？** 选择支持所选JSON格式的模型、缩短周期或更换配置；程序不会把占位内容假装成有效AI计划。

**取消后是否还收费？** 软件停止等待并丢弃迟到结果；已经到达服务端的请求仍可能计费。取消后可重试，草稿与原计划仍保留。

**不能应用或撤销？** 可能计划已有新编辑、打卡或专注记录，或任务受保护。重新预览，不要删除已有记录强行应用。

**时间不足？** 先缩减内容、调整可用日期，或创建延长周期的副本。时间上限优先于模型的建议。

**为什么关窗后仍在运行？** 默认进入托盘。需要停止时从托盘“完全退出”，也可在设置关闭收进托盘。
