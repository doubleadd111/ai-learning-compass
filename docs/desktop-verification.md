本机没有可用的 Windows Sandbox，因此未把本机隔离环境测试等同于全新 Windows 电脑验收。首个版本标记为公开试用，欢迎在另一台 Windows 10／11 x64 电脑按以下清单复核：

1. 不安装 Python，直接安装并打开软件，载入样例。
2. 添加自己的模型连接，获取模型列表或手动填写名称，测试一次 JSON 连接。
3. 创建计划、修改任务并打卡，完全退出再打开，确认记录仍在。
4. 备份、修改记录、恢复备份；在另一目录启动解压即用版检查同一用户数据可读取。
5. 在 Windows 允许通知时测试托盘提醒，测试专注暂停与休眠；确认完全退出后不再提醒。
6. 升级安装和正常卸载后，确认用户数据目录仍保留。
