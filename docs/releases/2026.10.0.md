# 学习罗盘 2026.10 · 首个 Windows 桌面试用版

适用 Windows 10／11 x64。安装后无需 Python 或 PowerShell。

## 下载

- `LearningCompass-2026.10.0-windows-x64-setup.exe`：推荐，按当前用户安装。
- `LearningCompass-2026.10.0-windows-x64-portable.zip`：解压整个文件夹后打开 LearningCompass.exe。
- `SHA256SUMS.txt`：下载校验值。`build-manifest.json`：依赖版本、源码摘要及产物摘要。
- `verification.json`：本机打包验收结果。GitHub 自动提供同标签源码压缩包。

## 本版功能

- 中文桌面五页导航、浅色／深色／跟随系统主题。
- DeepSeek、OpenAI、自定义兼容模型配置切换，支持 Chat Completions 与 Responses；自带 API Key，系统凭据保存或仅本次使用。
- Python、英语、考试及其他目标的学习计划，真实日期排期、多计划管理、任务编辑与打卡。
- 每周复盘与下周调整预览，保留历史与手动修改，支持撤销最近一次调整。
- 本机 SQLite 长期保存、旧版导入、JSON 导入导出、每日备份与整库恢复。
- 系统托盘、任务提醒、单实例、25／5 专注计时与独立人工补记。

## 验证与已知边界

70 项自动测试通过。付费模型请求以 Mock 验证，本轮开发未额外消耗作者 API 额度。公开 Streamlit 样例继续保留。

本机已验证移除外部 Python 后的启动、重启记录保留、单实例、Windows 凭据保存、按用户安装、覆盖安装及卸载保留学习数据。详细布尔结果见 `verification.json`。

本版为公开试用，未在另一台未安装 Python 的全新 Windows 电脑完成验收。移除外部 Python 的本机启动检查不等同于干净系统验收。真实 API、系统通知与不同 Windows 版本请按使用指南复核；API Key 不随备份迁移。

软件与安装包尚未代码签名，Windows 可能显示发布者或信誉提示。只从本仓库 Release 下载，先核对校验值；不需要关闭杀毒软件。提醒需要应用仍在运行（含托盘），并受 Windows 通知权限限制。

第一次打开，可先载入免费样例；需要生成时，到“设置 → 模型连接”填写自己的密钥，再测试连接。生成、连接测试和复盘会使用服务商额度。

完整中文指南与第三方声明随包提供；云同步、账号、原生 Claude／Gemini、自动更新不在本版范围。
