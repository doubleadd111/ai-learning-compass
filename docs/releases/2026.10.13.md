# 学习罗盘 2026.10.13 · 看清安排，随手记录

发布日期：2026-10-21。Windows 10／11 x64，继续作为公开试用版。合并 `2026.10.12.1`—`.2` 两次本机测试，不重发或改写旧版附件。

## 一眼看清整月，拖动前先确认

- 周视图可切换月视图，查看任务安排及每日负荷；全局负荷汇总全部活动计划和独立任务，不因筛选单计划而隐藏其他占用。
- 把任务拖到目标日期后，先显示原日期、新日期及容量变化，确认应用才写入。取消不改期，不挤走其他任务。
- 有学习记录、已完成/已复盘或其他受保护任务仍沿用原限制；数据在预览后变化时必须重新查看，不能覆盖新记录。预算冲突仍走原来的二次确认，不由拖动跳过保护。

## 按实际发生日查看学习量

- 新专注按真正学习的日期记录，跨午夜分配到两天；暂停或软件关闭的间隔不伪造成学习时间。
- “实际学习日历”提供月历、每日记录和每周趋势，可按计划/独立任务筛选，并选择包含归档；显示月内记录用时、学习天数及月内最长连续天数。
- 可给任务按日期人工补记，并预览撤销指定补记；原累计用时同步保留。仅撤销人工补记不会删除专注记录。
- 老版本仅有累计值、无法确定日期的部分，单独列为“未确定发生日期”，不混入某一天、月合计或趋势。这不是数据丢失，也不是将任务安排日当成学习日。
- 原“学习统计”依然是按任务安排日期归类的当前进度/累计用时快照；“实际学习日历”才是按可靠发生日期统计。两种口径并存，不表示过去每天的历史完成率。

## 想到就记，日期以后再定

- 新增快捷录入，可记任务名称、说明、预计分钟和优先级；既可加入已有计划，也可作为独立任务。
- 没选日期时进入“待安排收集箱”，不制造虚假日期、不占当日预算。整理时选择归属和日期，沿用原稳定ID进入正常任务流程。
- 窗口内支持 `Ctrl+Shift+N`。设置中可开启Windows全局快捷键，默认关闭；快捷键占用、修改失败会有提示，不悄悄替换其他程序的快捷键。
- 独立任务继续可从计划库固定任务箱查找，包括全部日期和已完成任务；待安排不是已删除，也不是暂停计划。

## 把重点放到前面，不偷偷改计划

- 可设普通/低/中/高优先级、置顶和“今天重点”；今日页可只看重点，任务右键也可整理。
- 这些标记影响展示与排序，不自动改安排日期、预计分钟、预算或完成状态，不会因为添加步骤或标重点自动完成任务。
- 计划历史保留整理设置；回溯仍保留当前学习证据，不覆盖已完成状态、笔记和专注用时。

## 读得清楚，减少重复等待

- 当前页按需刷新，同次刷新复用只读数据；其他页面进入时更新，不缓存跨操作的旧资料。减少重复查询，不宣称所有电脑的冷启动延迟已解决。
- 任务说明、完成产出和笔记自动换行，预留多行阅读空间；长表单可以滚动，保存/取消始终在底部。手动、快捷、周期任务及规划目标、偏好、追问意见等同类输入同步调整。
- 已复盘任务的说明可选中复制，但仍不能编辑锁定内容；仅打开、查看或取消不会修改记录。
- 学习日历将日期、日期旁的今日点、下方用时分开，不再重叠；摘要、每日及每周用时显示精确分秒，月历仅用简写分钟。底层秒数不变。
- 保留既有蓝灰主题、明暗配色、平级工具窗口、中文提示和右端滚轮防误触，不另起一套界面风格。

## 版本、下载与数据安全

1. 安装版：`LearningCompass-2026.10.13-windows-x64-setup.exe`；解压即用版：`LearningCompass-2026.10.13-windows-x64-portable.zip`。便携版须完整解压，保留 `_internal` 文件夹；无需另装Python或PowerShell。
2. 升级前在设置里备份，并从托盘选择“完全退出”。数据仍在 `%LOCALAPPDATA%\LearningCompass`，正常升级不清空资料；程序不会强制结束你正在操作的学习罗盘。
3. 数据库升级为schema8，计划JSON为格式7，继续接受旧导入。旧库先备份、在临时副本迁移校验，再原子替换；整库备份包括待安排、重点、按日学习证据、回收站和历史。
4. 原任务ID、日期、状态、笔记、原累计用时及学习记录保留。新数据不能直接让旧程序读写；回退必须同时恢复对应升级前数据库备份，不能只换旧exe。
5. API Key不进入数据库新增字段、学习历史、快照或发布包，换电脑后需重新设置；不自动调用真实模型。
6. 版本使用完整年份：`2026.10.13`是本月第13次可用更新；之后若继续本机测试，从`2026.10.13.1`开始。主更新日志只汇总最终变化，旧测试在基线版下保留摘要并注明合并去向，旧日志完整归档。

附件包含安装包、便携包、SHA256SUMS.txt、build-manifest.json及脱敏verification.json。请只从本仓库下载并核对摘要。程序未代码签名，可能有发行者提示，不要关闭安全软件来绕过警告。GitHub另外提供标签源码zip/tar.gz。
