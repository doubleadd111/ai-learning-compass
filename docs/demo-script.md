# 两分钟演示脚本

录屏前用 `APP_MODE=demo` 启动应用。录屏中不要展示 `.env`、邀请码或终端中的密钥。此脚本只是录制指引；项目目前没有已经录好的演示视频。

1. **0:00–0:20，样例**：打开应用，说明公开样例无需 API，可直接体验两周 Python 入门计划。展开第一周，展示任务时长与具体产出。
2. **0:20–0:55，每日记录**：将第一天标记为“已完成”，填写实际用时、难度和简短记录；将第二天标记为“延期”，第三天标记为“已完成”。保存后展示进度变化。
3. **0:55–1:25，每周复盘**：点击“生成本周复盘并调整后续计划”。展示完成率、难度、延期任务如何进入第二周，以及调整后任务未超过用户时间上限。
4. **1:25–1:45，导出导入**：下载 JSON；在新会话中上传文件，检查计划与记录恢复。
5. **1:45–2:00，质量证据**：展示 README 中的测试命令、30 组评测输入和 `docs/evaluation-sample.json` 的一次真实调用结果；明确没有把一次结果说成总体通过率。

公开发布后再补上实际视频链接与日期。
