# 桌面界面约定

后续新增或修改界面必须沿用现有学习罗盘风格，不为单个弹窗另造配色或按钮样式。

- 使用 `desktop/theme.py` 的明暗主题令牌。浅色画布#F6F7F9、白色卡片、正文#202938、辅助文字#68758A、主色#356CF6；不硬编码仅浅色可读的文字或背景。
- 正文使用应用字体与13px字号，标题沿用brand，数字可适度突出。12–24px留白、圆角卡片、按钮悬停/按下/键盘焦点反馈保持一致。
- 确认操作复用 `desktop.confirmations.ConfirmationDialog` 的标题、短说明、可滚动内容、固定操作栏。容量确认使用 `CapacityConfirmDialog`，逐日期/周次显示分钟数，避免系统大黄图标与密集文字。
- 全部操作文案为中文，不保留OK、Cancel、Show Details等标准按钮。`desktop.localization` 对Qt内置按钮提供统一中文后备；服务商和模型ID保留原名。
- 可能保存超限安排、删除、覆盖等操作默认取消或返回调整。主按钮名称说明具体动作；Enter、Escape、关闭窗口必须有回归测试。
- 计划删除放在“更多操作”的危险操作区，不与日常任务按钮并列。复用 `DeletePlanDialog` 展示完整名称和影响范围，输入必须完全匹配“确认删除”才启用删除按钮；回车/Esc/关窗不删除。存储层重新检查版本与专注，并在每次删除前单独备份，失败不删。
- 常用按钮旁的操作浮层复用 `PopupSurface` 的圆角、透明角与轻边框，不使用原生菜单分隔线/系统阴影；菜单项保留中文、悬停、键盘焦点和Esc/外部点击收起。计划历史使用时间列表+当前/目标差异卡，不堆叠系统消息框或显示原始JSON字段；回溯仍需明确确认。
- 新窗口不永久置顶其他软件。指南打开时复用单一窗口，关闭后释放并保留阅读状态；必须验证“关闭指南→关闭来源→从别处重开”，不能只验证首次出现。
- 数值/下拉/日期/时间输入沿用已有右端滚轮限制。小窗口应滚动内容，不让底部操作被挤出；同时检查明暗主题与键盘操作。
- 验收需截图检查实际字号、留白、换行、默认按钮和无英文；新功能同步维护离线指南与更新日志。只通过对象属性或Mock不代表真实窗口生命周期正确。
